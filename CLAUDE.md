## Project Overview

GBM Senescence Atlas — interactive web application for exploring 2.26M single cells from a Glioblastoma (GBM) aging/senescence study. Uses deck.gl for WebGL-based rendering of million-cell UMAP plots with multi-dimensional clinical filtering.

## Tech Stack

- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS + Zustand (state) + deck.gl 9.x
- **Backend**: FastAPI (Python 3.10+, conda env `web`) + PyArrow (Arrow IPC serialization)
- **Data Transfer**: Apache Arrow IPC binary streams for cell data; JSON for small metadata
- **Data Pipeline**: AnnData h5ad → preprocessed binary (float32/uint8) + JSON (`preprocess/`)
- **Rendering**: deck.gl OrthographicView — HeatmapLayer (density) / ScatterplotLayer (detail)

## Commands

```bash
# Activate environment
conda activate web

# Run preprocessing pipeline (reads h5ad → data/processed/)
python preprocess/run_all.py

# Run individual preprocessing steps
python preprocess/step1_extract.py   # UMAP coords + metadata → binary
python preprocess/step2_senescence.py # Compute senescence scores
python preprocess/step3_hexbin.py     # Hexbin aggregation
python preprocess/step4_stats.py      # Centroids, patients, DE, correlation
python preprocess/step5_downsample.py # 1% stratified downsample

# --- Development (two terminals or use start.sh) ---

# Backend (port 8050)
pip install -e ./backend
uvicorn backend.server.app:app --host 0.0.0.0 --port 8050 --reload

# Frontend (port 5174, proxies /api → backend)
cd frontend && npm install && npm run dev

# Or launch both at once:
./start.sh

# --- Production ---
./run.sh   # builds frontend, serves via backend on port 8050
```

### Data Pipeline (`preprocess/`)

Converts 62GB h5ad (2.26M cells × 57K genes) into compact files served by the API:

- `coords.bin` (float32, ~17MB) — UMAP x,y pairs
- `meta.bin` (uint8/uint16, ~13MB) — encoded categorical columns
- `schema.json` — category label maps, column layout, UMAP bounds
- `senescence.bin` (float32, ~8.6MB) — normalized senescence scores [0,1]
- `senescent_class.bin` (uint8) — binary classification (top 25%)
- `hexbin.json` — pre-aggregated hexagonal bins
- `centroids.json`, `patients.json`, `de_results.json`, `correlation.json` — pre-computed stats

The meta.bin layout: first 6 columns are uint8 (nCells bytes each), last 2 (donor_id, Sample) are uint16 stored as raw bytes. Column order matches schema.json.

### Backend (`backend/server/`)

FastAPI app with Arrow IPC data transfer:

- **Arrow IPC endpoints:**
  - `GET /api/cells` — all cell data as single Arrow RecordBatch (~48MB): x, y, senescence, CellType, CellType_Level2, IDH, stage, age_Group5565, sex, donor_id, Sample
  - `GET /api/gene/{name}` — gene expression as Arrow RecordBatch (single Float32 column)
- **JSON endpoints:** `/api/schema`, `/api/hexbin`, `/api/centroids`, `/api/patients`, `/api/de`, `/api/correlation`, `/api/stats`
- **Dynamic:** `/api/region?xmin&xmax&ymin&ymax` (bounding box cell query)

Key modules:
- `data_cache.py` — singleton that lazy-loads numpy arrays from binary files, builds and caches Arrow IPC bytes
- `arrow_io.py` — `build_cells_batch()` wraps numpy arrays as Arrow RecordBatch, `serialize_ipc()` writes to IPC stream
- `gene_service.py` — reads gene expression from h5ad on demand, normalizes, caches to disk, returns Arrow IPC

### Frontend (`frontend/src/`)

React 18 SPA built with Vite. No CDN dependencies — all packages via npm.

**Zustand Stores (5 slices):**
- `dataStore` — cell TypedArrays from Arrow IPC (coords, senescence, meta columns), schema, pre-computed JSON data
- `viewStore` — deck.gl viewport state, render mode (overview/density/detail), visible cell count
- `filterStore` — per-column active category filters, Uint8Array filter mask, donor highlight
- `colorStore` — color mode (celltype/celltype2/senescence/gene), gene expression Float32Array
- `uiStore` — loading state, active analysis tab, selected donor

**Key Hooks:**
- `useInitData` — orchestrates initial data loading (schema → Arrow cells → JSON endpoints → init filters)
- `useDeckLayers` — computes deck.gl Layer[] from all store state, memoized

**Components:**
- `UmapView` — deck.gl `<DeckGL>` with OrthographicView
- `FilterPanel` / `FilterChip` — schema-driven category filter chips
- `ColorModeSelect` — dropdown + gene search input
- `Legend` — categorical (color dots) or continuous (gradient bar)
- `Header` — stats bar (total/filtered/visible counts, render mode)
- `AnalysisPanel` — tabbed bottom panel (DE waterfall, correlation heatmap)

### Rendering Strategy

- **Density (>5K visible cells)**: `HeatmapLayer` from `@deck.gl/aggregation-layers` — GPU-aggregated, weight = senescence or gene expression
- **Detail (<5K visible)**: `ScatterplotLayer` — individual cells colored by cell type or continuous scale
- **Overview (no filters, hexbin available)**: `ScatterplotLayer` with pre-aggregated hexbin data
- Centroid labels (`TextLayer`) always rendered on top

### Data Flow (Arrow IPC)

```
Backend: numpy arrays → pa.RecordBatch → pa.ipc.new_stream() → bytes (cached)
    ↓
HTTP Response (application/vnd.apache.arrow.stream)
    ↓
Frontend: fetch → arrayBuffer → tableFromIPC() → zero-copy TypedArray views
    ↓
Zustand stores → useDeckLayers hook → deck.gl WebGL render
```

## Key Data Facts

- 2,259,122 cells, 57,166 genes
- 9 CellType categories, 17 CellType_Level2 categories
- IDH values cleaned: "WT" + "IDH wildtype" merged to "WT"
- 517 donors, 577 samples, 45 author studies
- Senescence scored using curated gene set (CellAge + SenMayo markers)
- Source h5ad is a symlink at `data/AllSample_obj.h5ad`
